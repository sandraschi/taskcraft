# taskcraft MCP tools

Generated by `taskcraft tools --markdown`. Do not edit by hand: a test fails when this file
is out of date. Every tool is also a CLI verb (`taskcraft --help`). Dotted names (`app.verb`) are accepted.

| Tool | What it does | Required | Optional |
|---|---|---|---|
| `task_status` | Tracker status: counts (open, in progress, urgent, overdue), projects, demo flag. | - | - |
| `task_project_create` | Create a project with a 2-10 char key (issues become KEY-n). Optional repo_path enables git sync. | `key`, `name` | `repo_path` |
| `task_project_list` | List projects. | - | - |
| `task_issue_create` | Create an issue. kind defaults to task; parent puts it under an epic, story, task or bug of the same project (not under a subtask; an epic has no parent). | `project`, `title` | `assignee`, `description`, `due_date`, `estimate`, `kind`, `labels`, `milestone`, `parent`, `priority`, `status` |
| `task_issue_list` | List issues, urgent first. Finished issues are hidden unless include_finished or an explicit status filter. | - | `include_finished`, `label`, `limit`, `milestone`, `priority`, `project`, `status`, `text` |
| `task_issue_show` | One issue with relations, open blockers, linked commits, children, rollup (points and percent done over all descendants, canceled excluded), comments, watchers and full history. | `issue` | - |
| `task_issue_reparent` | Put an issue under a parent in the same project, or detach it with parent=null. Refused: cycles, an epic with a parent, anything under a subtask, cross-project parents. | `issue`, `parent` | - |
| `task_issue_update` | Change fields. Pass null to clear estimate/assignee/milestone/due_date. labels replaces the set. Changing kind to epic needs no parent; to subtask needs no children. | `issue` | `assignee`, `description`, `due_date`, `estimate`, `kind`, `labels`, `milestone`, `priority`, `title` |
| `task_issue_move` | Change status. Moving to in_progress/in_review/done is refused while an open issue blocks it, unless force=true. | `issue`, `status` | `force` |
| `task_relation_add` | Relate two issues. 'blocks' edges may not form a cycle. | `source`, `kind`, `target` | - |
| `task_relation_remove` | Remove a relation. | `source`, `kind`, `target` | - |
| `task_milestone_create` | Create a milestone in a project. | `project`, `title` | `due_date` |
| `task_milestone_list` | Milestones with progress (issues and points done/total). | - | `project` |
| `task_milestone_close` | Close a milestone. | `project`, `title` | - |
| `task_board` | Kanban lanes for a project: cards per status, points, blocked flags. | `project` | - |
| `task_git_sync` | Read the project repo's git log, link commits mentioning KEY-n, close issues on 'closes/fixes/resolves KEY-n'. Needs --allow-path covering the repo. | `project` | `max` |
| `task_inbox_drain` | Turn events from other craft apps (deskcraft ticket.escalated, contractcraft contract.deadline) into issues; teamcraft capacity.changed is stored per week and shown in task_status. | - | - |
| `task_demo_seed` | Fill an EMPTY tracker with a labelled demo project. | - | - |
| `task_person_list` | People (assignees, comment authors, mention targets) with their @handles. | - | `include_inactive` |
| `task_person_add` | Add a person. handle (2-32 of a-z 0-9 . _ -) is derived from the name when omitted; teamcraft_code links the teamcraft employee. | `display_name` | `handle`, `teamcraft_code` |
| `task_comment_add` | Comment on an issue as the acting user. @handle mentions a person and makes them a watcher; unknown handles are listed in unknown_mentions and the comment is still saved. | `issue`, `body` | - |
| `task_comment_list` | Comments of an issue, oldest first. Deleted comments are included with deleted=true. | `issue` | - |
| `task_comment_edit` | Edit your own comment. Pass the version you saw to refuse the edit if someone changed it meanwhile. | `comment`, `body` | `version` |
| `task_comment_delete` | Delete your own comment (soft: flagged, body kept in history). | `comment` | `version` |
| `task_watch` | Start (watch=true, default) or stop watching an issue for a person (@handle or name). | `issue`, `person` | `watch` |
