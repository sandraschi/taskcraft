# taskcraft v0.1.4

Local issue tracker bound to git refs. Windows x64.

## Downloads

- `taskcraft-app.exe`: the desktop window.
- `taskcraft.exe`: CLI and MCP server.
- `taskcraft-0.1.4-setup.exe`: per-user installer.
- `taskcraft-v0.1.4.mcpb`: MCP bundle.

## What is new

- The window menu is File, Edit, View, Window, and Help. View switches the five screens. `--smoke` checks the menu.
